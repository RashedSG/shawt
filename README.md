# شوط (Shawṭ)

منصة أداء وتحمل للإمارات — موقع ثابت (Static site) من ثلاث ملفات: `index.html` + `style.css` + `app.js`، بدون بناء (build step) وبدون خادم.

## قبل النشر — خطوة واحدة

في `robots.txt` و`sitemap.xml` بدّل `REPLACE-WITH-YOUR-DOMAIN` بالدومين الفعلي بعد ما تختار الاستضافة.

## التشغيل محلياً

أي خادم ملفات ثابت يكفي، لأن المتصفح يمنع `fetch` من `file://`:

```
python3 -m http.server 8000
# افتح http://localhost:8000
```

أو `npx serve .` إذا عندك Node.

## النشر (اختر واحدة، الثلاث مجانية)

**GitHub Pages** — ينشر الموقع لكنه **لا يشغّل دوال**، فميزة "اسأل المدرب" تُخفي نفسها تلقائياً عليه. بقية الموقع يعمل كاملاً.
1. ارفع محتوى هذا المجلد لمستودع GitHub.
2. Settings → Pages → Source: فرع `main`، مجلد `/root`.
3. الموقع يطلع على `https://<username>.github.io/<repo>/`.

**Netlify / Cloudflare Pages**
اسحب المجلد مباشرة في لوحة "Deploy" — بدون أوامر بناء، لأنه HTML/CSS/JS خام.

## البنية

```
index.html          — الهيكل والتنقل فقط
style.css            — كل التنسيق
app.js               — كل المنطق: التوجيه، الحالة، الخطة، الطقس، الاختبارات
coach.js             — طبقة "اسأل المدرب" في صفحة الخطة
functions/api/coach.js — الوسيط الذي يحمل مفتاح API (لا يعمل على GitHub Pages)
manifest.webmanifest — PWA: يسمح بـ"إضافة إلى الشاشة الرئيسية"
robots.txt / sitemap.xml — فهرسة محركات البحث (عدّل الدومين أولاً)
img/                 — الصور المستخدمة فعلياً في الكود
```

**ملاحظة PWA:** أيقونة الشاشة الرئيسية SVG (نفس الشعار) — تشتغل كاملة على أندرويد/كروم. آيفون/سفاري قديماً يفضّل PNG؛ إذا تبي أيقونة iOS مضبوطة بكسل بكسل، ارفع `img/logo.svg` على أداة مثل realfavicongenerator.net وحطّ الناتج مكان `apple-touch-icon`. ما ضفت service worker (تخزين أوفلاين) عمداً — الموقع يعتمد على طلب طقس حي، وservice worker غير مُختبر جيداً أخطر من عدمه.

كل الحالة (البروفايل، الخطة، الأنشطة، الاختبارات) تُحفظ في `localStorage` على جهاز المستخدم — ما فيه خادم قاعدة بيانات. الحساب → الخصوصية والبيانات فيه تصدير واستيراد JSON لنسخة احتياطية.

**استثناء واحد:** إذا فعّلت "اسأل المدرب"، فسؤال المستخدم وملخص مشتق من أرقامه (الجاهزية، اللياقة والتعب، مناطق الإيقاع، رايات السلامة، الملاحظات الصحية المسجّلة) يُرسلان إلى Anthropic لتوليد الرد. البطاقة تقول هذا للمستخدم صراحةً. بقية الحالة ما تغادر الجهاز.

## اسأل المدرب (اختياري)

بطاقة في صفحة الخطة تشرح أرقام المستخدم كما حسبها التطبيق. **المدرب يشرح ولا يحسب** — الجاهزية ومناطق الإيقاع والحمل تبقى من `readiness()` و`paceZonesFromCooper()` و`fitnessFatigue()` في `app.js`، والنموذج يقرأها كما هي. هذا يبقي النتائج ثابتة وقابلة للتكرار، ويحصر الخطأ.

**الميزة تُخفي نفسها تلقائياً على الاستضافة الثابتة.** عند فتح صفحة الخطة تسأل `coach.js` عن `/api/coach` سؤالاً واحداً؛ إذا ما رد (404 على GitHub Pages مثلاً) فالبطاقة لا تُعرض أصلاً — لا زر مكسور ولا رسالة خطأ. الصفحة تبقى كما كانت تماماً.

### التشغيل

المفتاح لا يُوضع في `coach.js` أبداً — أي مفتاح في كود المتصفح مكشوف للجميع. مكانه متغيّر بيئة عند المستضيف:

1. انشر على Cloudflare Pages (أو Netlify/Vercel — يحتاج نقل `functions/api/coach.js` لمسار المزوّد).
2. أضف متغيّر البيئة `ANTHROPIC_API_KEY` من لوحة التحكم. المفتاح من [console.anthropic.com](https://console.anthropic.com).
3. المزوّد يثبّت `@anthropic-ai/sdk` من `package.json` تلقائياً. الموقع الثابت نفسه يبقى بلا بناء.

للتجربة محلياً: `npx wrangler pages dev .` بعد `npm install`.

### قبل الفتح للعموم

الوسيط الآن يتحقق من نفس الأصل ويحدّ طول السؤال (600 حرف) وعمق المحادثة (12 رسالة)، لكن **ما فيه تحديد معدّل**. أي شخص يعرف الرابط يقدر يستهلك رصيدك. قبل النشر العلني أضف تحديد معدّل — قاعدة Rate Limiting في Cloudflare، أو عدّاد في KV.

### التكلفة

تقريباً 2–4 سنت للرسالة على `claude-opus-5`. الموديل والجهد في أعلى `functions/api/coach.js`.

## الطقس

يُجلب من [Open-Meteo](https://open-meteo.com) — بدون مفتاح API، لكن **مجاني للاستخدام غير التجاري فقط** (رخصة CC BY 4.0). إذا الموقع بيصير تجارياً، راجع خطط Open-Meteo المدفوعة أو بدّل المصدر. التحذيرات الرسمية (ضباب، غبار، عواصف) موصولة بموقع [المركز الوطني للأرصاد](https://www.ncm.gov.ae) — التطبيق ما يستبدلها.

## قيود معروفة

- بدون حساب مستخدم حقيقي أو مزامنة بين الأجهزة — كل شي محلي على المتصفح.
- خلاصة المجتمع تجريبية (بيانات ثابتة في الكود، مو مستخدمين حقيقيين).
- تواريخ الفعاليات في `EVENTS()` بداخل `app.js` تقديرية لموسم 2026–27 — تحقق من مواقع المنظمين قبل الاعتماد عليها، وحدّثها يدوياً كل موسم.
- المسارات في `ROUTES` محدودة العدد — أضف المزيد بنفس الشكل عند الحاجة.

## للمطوّر

`app.js` منظم بترتيب: أيقونات → حالة (state) → ترجمة (T) → منطق الخطة/الجاهزية → طبقة الأداء (تسجيل جديد، طقس، اختبارات) → واجهات (view*) → التوجيه → ربط الأحداث. أي نص ظاهر للمستخدم موجود في كائن `T.ar` / `T.en` فقط — لا نص عربي أو إنجليزي مثبّت داخل دوال العرض.
